Логические строки и числовые ID цитат нормализуются, явное несовпадение не повышается, отказ модели отображается отдельно. Неизвестная дата теперь не меняет подтверждённую связь текста с темой, но запрещает автоматическое включение в Excel; свежий режим по-прежнему требует подтверждённого времени.

Поиск дополнен запросами с географией, периодом и новостной формулировкой, чтобы каталоги услуг не занимали весь бюджет. Широкие запросы сохранены. ## Поиск «Аделинчики Саратов» — исправление полноты

По последующей просьбе пользователя обычный запрос больше не превращается в обязательную непрерывную фразу. Ключевые слова могут находиться в разных частях оригинала; кавычки пользователя сохраняют строгую фразу. Географию из запроса проверяет модель по смыслу, включая региональную принадлежность участников. Название команды сохраняется буквально, «Апельсинчики» не принимаются вместо «Аделинчики». Дополнительный поисковый запрос закрепляет неизвестное словарю название в кавычках отдельно от города.

Убраны обязательные дата и название региона из первого запроса обнаружения. Период и география по-прежнему проверяются после получения оригинала. Обход всех выбранных площадок выполняется до применения общего бюджета; ссылки обрабатываются поочерёдно между площадками с приоритетом совпадений в заголовке. VK опрашивается отдельно по vk.ru и vk.com, MAX — по max.ru.

Публичный пост MAX теперь извлекается из контейнера сообщения. Страница канала не подменяется постом. Проверено на настоящем HTML MAX: извлечены 640 символов сообщения; нерелевантные объявления отвергнуты по словам запроса. В данной выдаче запрос с обязательным названием команды не нашёл постов MAX. Это не утверждение, что таких постов вообще нет.

VK по найденным прямым ссылкам возвращает динамическую оболочку без текста; мобильный вариант — страницу несовместимого браузера. Проверка сертификатов и ограничения доступа не отключались. Ссылки с совпадением в поисковом описании сохранены отдельно для ручного открытия, с явной пометкой о непроверенных содержании и дате. Они не считаются проверенными оригиналами и не попадают в Excel автоматически.
