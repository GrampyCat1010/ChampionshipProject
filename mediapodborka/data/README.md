# Справочник городов

`cities.csv` — неизменённая копия https://github.com/hflabs/city/blob/master/city.csv,
получена 19 октября 2026 года. Автор: HFLabs; данные адресов из DaData.ru.
1107 записей. Условия: Creative Commons Attribution-ShareAlike 4.0 International
(https://creativecommons.org/licenses/by-sa/4.0/).
Оригинальное описание и указание лицензии сохранены в `cities-upstream-README.md`.

Справочник служит для проверки введённой пары город/регион, не является
актуальным государственным адресным реестром. Новые города и переименования
требуют обновления копии. Неизвестная пара не принимается молча: предлагается
проверить название или убрать город. Произвольные регионы без города допустимы.
